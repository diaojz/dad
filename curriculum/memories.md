# 爸爸讲过的往事（保持一致，按信追加）

| 信 | 往事 | 关键细节（不得改动） |
|---|---|---|
| 第1封 | 儿子请爸爸纠正 | 儿子打电话说怕经验变成偏见、请爸爸纠正，爸爸挂电话后在阳台站了好一会儿；这是「爸爸的信」的起头 |
| 第1封 | 跟老周下棋被孙子点破 | 2026 年国庆儿子一家回县城；楼下棋友老周，下了十来年象棋；老周一出车，爸爸就用顶了十来年的老办法；孙子蹲在旁边指出炮打过去就将死；爸爸听了赢棋，老周说请了外援不算 |
| 第2封 | 你妈拧不开辣椒酱 | 2026-11 中午；你妈秋天做的辣椒酱，垫毛巾拧不开，爸爸一下拧开；给儿子留了一罐过年拿 |
| 第2封 | 修理铺扛电视 | 显像管电视三十多公斤，一天扛上扛下好几趟 |
| 第2封 | 50 岁腰椎间盘突出 | 2008 年；平躺三个礼拜，你妈扶着翻身；康复科年轻医生：「腰不是搬东西搬坏的，是撑腰的那几块肉不够了」；病因是修理铺生意变淡后久坐柜台 |
| 第2封 | 提水上五楼 | 此后每天做康复动作、提两桶水上五楼浇阳台菜，十八年腰没再犯（家住五楼） |
| 第2封 | 架着儿子看钓鱼 | 儿子小时候，爸爸把他架在脖子上去河边看人钓鱼 |
| 第3封 | 储藏室的黑白电视 | 十四寸黑白机，厂里最后一批货，1997 倒闭那年自掏钱买回；2026-11 收拾储藏室翻出，接电拍两下还能亮；旋钮一档一档咔哒响，儿子小时候爱拧被骂过；现在摆在储藏室门口没扔 |
| 第3封 | 投票反对上彩电线 | 九十年代初厂里开会讨论上彩电生产线，爸爸投反对票，理由「彩电一千多块，工人月薪一百来块，谁买得起」，几个老师傅点头 |
| 第3封 | 儿子说 AI 额度紧 | 儿子跟爸爸提过用的 AI 额度紧、得省着用 |
| 第4封 | 你妈读回信 | 儿子回信说每周两次健身房，你妈念两遍（第二遍戴老花镜自己看），说「一个礼拜两回，还行」，晚饭多炒了个菜 |
| 第4封 | 记毛病的硬皮本 | 开铺子时一台一行记牌子/型号/症状/坏件；有一页「无光栅，先查行输出，再查高压包，别急着换管子」带箭头；2005 年前后变稀，之后几乎空白；现在放回柜子没扔 |
| 第4封 | 换板 | 2005 年前后兴起，打电话让省城批发市场寄整块板，半个钟头换好，那几年铺子一半生意靠它 |
| 第4封 | 老太太的彩电 | 约 2010 年，老伴去世留下的彩电，板子买不到只能自己查；手稳但想不起先量哪一路，以前二十分钟的毛病弄到天黑；老太太坐门口小板凳等不催；修好塞十个鸡蛋 |
| 第4封 | 儿子说先让 AI 查 | 儿子电话里说现在查毛病大多先让 AI 看一遍再自己看，爸爸当时没接话 |
| 第4封 | 头场霜盖辣椒 | 2026-11 头一场霜，旧报纸盖阳台辣椒；你妈说盖太严会闷坏 |
| 第5封 | 辣椒揭报纸 | 揭开后叶子缓过来，你妈说「算我蒙对的」 |
| 第5封 | 孙子视频问辣椒 | 礼拜天视频，孙子问辣椒为什么是红的；爷爷从叶子里的绿讲起，孙子走神；奶奶问「你觉得呢」，孙子说太阳晒的，奶奶追问屋里的红不红，一问一答近十分钟十几趟，孙子从冰箱拿辣椒比划；奶奶说爷爷「一开口就是上课」 |
| 第5封 | 柜台写作业 | 铺子开张那年（1998）儿子十岁，放学趴柜台那头写作业，爸爸这头焊板子；问电视里的人怎么进去、烙铁为什么不能碰；爸爸边焊边讲，讲完「快写作业」；电视那问答「信号」，儿子点头没懂，爸爸没再问 |
| 第5封 | 爷爷话少 | 爸爸的父亲一天跟他说不了十句话 |
