# 认知地图（选题罗盘，不是排课表）

父亲每天从这里挑，**按儿子最近的状态和回信决定**，不机械轮转。同一领域不连续超过两天。

| 领域 | 代号 | 举例（只是方向，不是题目） |
|---|---|---|
| 思维与决策 | mind | 路径依赖、二阶思维、基础比率、可逆与不可逆决策、经验的半衰期 |
| 工程与技术演进 | craft | 什么经验在贬值/升值、「写代码」与「解决问题」的分离、复杂度从哪来 |
| AI 时代的工作 | work | 目标表达、验收能力、判断力的定价、什么不该自动化 |
| 钱与风险 | money | 复利与时间、尾部风险、保险的本质、收入结构 |
| 身体 | body | 睡眠、力量训练、久坐、视力、中年体检该看什么 |
| 人与关系 | people | 倾听、冲突、信任的建立、怎么请人帮忙 |
| 做父亲 | family | 孩子的注意力、无聊的价值、示范胜过说教、夫妻关系 |
| 历史与世界 | world | 技术革命的历史回声、制度、地理、人口 |
| 学习本身 | learn | 刻意练习、提取练习、遗忘曲线、读书方法 |
| 自我 | self | 情绪、意义感、中年转折、与自己的旧观点和解 |
| 自然与科学 | nature | 演化、概率、物理直觉、宇宙尺度带来的谦卑 |

三种信的配比大致：校准 50% / 补全 35% / 确认 15%。
